Công nghệ đề xuất

Đề chỉ cho dùng một số công nghệ nhất định, ví dụ .NET, JSP/Servlets, SQL Server. Phương án dưới đây vẫn nằm trong danh sách đó, chỉ là bản mới hơn.

BackendASP.NET Core MVC (C#). Nếu nhóm học Java thì dùng JSP + Servlets + JDBC.
CSDLSQL Server, viết script CREATE + INSERT dữ liệu mẫu
FrontendHTML, CSS, JavaScript, Bootstrap 5 (responsive)
Công cụVisual Studio / VS Code, SSMS, Git, draw.io (vẽ ERD)
Chạy localGắn tên miền www.karneltravelguide.com vào file hosts để đúng yêu cầu URL

Thiết kế CSDL gợi ý (ERD)

Quy tắc cần nhớ

Mỗi nhóm chỉ được nộp một lần. Đã nộp rồi thì không được thêm hay sửa file. Hãy dò hết checklist ở giai đoạn 6 trước khi bấm nộp.
  • Tiêu đề email bắt đầu bằng STATUS:, DOUBT: hoặc PROJECT SUBMISSION:.
  • Status mail gửi kèm ZIP gồm code, script CSDL và ảnh chụp màn hình, qua mục Query/Status.
  • Code phải có comment, giải thích được logic.
  • Backup dữ liệu mỗi ngày, đẩy code lên Git sau mỗi buổi làm.
